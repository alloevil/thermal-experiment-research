# 第一版任务闭环协议

目标：固定允许试验库，辨别散热增强与传感器负零偏，不设计任意输入、不控制设备。

模型：复用radiation/model.py，24单元拟合/规划；仿真评价端96单元。教学参数及几何不是RTP。所有试验独立从296.15K均温起始，用户必须自行确认此条件。已有数据也要明确对应哪个输入及时间/位置。

候选A convection：对流乘子[1,1.2,1.4,1.6]，零偏0K。候选B offset：对流乘子1，零偏[0,-0.3,-0.6,-0.9]K。共同干扰参数：吸收增益和热容量乘子各[0.95,1,1.05]，共36个粒子/解释。两解释先验各0.5，解释内网格均匀，基线点存在重叠。网格是显式研究先验，不是实测置信范围。

观测模型：独立高斯、实验内固定已知sigma。数据似然必须使用完整粒子集合，不能只用最佳拟合。记录粒子ESS与模型概率。不是连续参数后验，候选外真值/相关噪声/初温误差会影响结果。

试验：initial为低功率60s末态中心温度单点，sigma=0.25K。下一步允许heat_low、heat_high、cooldown三个热试验，及reference零功率独立参考对照试验。输入、观测时刻、每次费用由case.json明确固定。预算是可用额度与最多一个下一试验，不混淆为累计等时长预算；reference默认标为不可用，需要显式确认独立参考。推荐只可从enabled且cost<=budget的集合选择；报告费用、总时长、各区轨迹和每个观测的位置/单位/噪声。

信息增益：以当前后验预测分布蒙特卡洛抽样128次（固定种子20261001），计算模型标签的期望熵减少。各试验共用抽样粒子和标准正态噪声前缀。0.01 nat以下不给强行推荐。区间是有限粒子预测含测量噪声的蒙特卡洛5/95百分位，非校准的可靠区间。输出两解释各预测范围和可辨别的主要观测，不宣称每一箭头为因果证明。

适配性：对每一解释取网格内最佳观测残差的chi-square尾概率。若两解释的全历史残差均p<0.001，返回unsupported；若追加观测在两解释网格内也都p<0.001，保留unsupported状态。这个保守检查不是精确显著性检验（参数选择后分布不同），不能保证识别所有模型错误。若未拒绝且某模型后验>=0.95，返回supported_hypothesis（仅在候选集合内），其余ambiguous。不输出根因已证实或安全批准。

demo：一个独立隐藏对象生成已有观测，运行真正recommend，模拟所选试验，再调用update；另外运行完全等价候选和两解释都不适配的案例，不能脚本硬编码最终结论。

小规模对照：16个新隐藏对象，8个散热增强、8个零偏，连续参数不必落在离散网格上。共同gain/capacity在[.97,1.03]，物理/噪声种子20261002。initial同数据，热试验集合相同（不开放reference），每次恰好一个cost=1试验，sigma固定。比较EIG、固定cooldown、随机选择、按两模型预测均值差/总预测方差评分的简单分离度；最后一项是模型辨别启发式，不冒称D-opt或SOTA。评价后验>=.95的覆盖率/已决错误数、弃权、unsupported、Brier及调用/时间。所有策略在同对象相同候选试验使用同一份噪声结果。这个16例实验不是通用性能/用户需求证据。

验收：输入验证与预算/可用性、追加数据不可重复、两模型等价时弃权、异常观测拒绝、同一后验更新顺序不改变结果、真实CLI闭环、24/96单元预测差<0.05K（预设固定案例），对照保留全部结果。未知失败不能通过换随机种子、修改阈值或原假设范围掩盖。界面仅本地JSON和Markdown；不新增服务或依赖。

实施补充：首次演示和同预算评价后，为完成用户输入约束功能，增加max_predicted_temperature_K字段（默认380K）。按全粒子网格的物理温度（不含传感器零偏）筛选未来试验，拒绝超限候选，不影响历史观测似然。是离散预测筛选，不是连续/真实安全保证。首次输出保留在development，最终对照按相同对象/种子/预算重新执行，以确认筛选未暗改结果。
