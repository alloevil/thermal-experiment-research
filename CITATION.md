# Citing this research archive

Repository: https://github.com/alloevil/thermal-experiment-research . There is not yet a confirmed project-specific paper, DOI, tagged software release or finalized author list for this archive. Do not cite it as a peer-reviewed paper, and do not use a third-party reference's DOI as this project's DOI.

## For a result or method

1. Link the **specific study report and its protocol**, not only the repository homepage. [Project facts](docs/PROJECT_FACTS.md) maps representative claims to their sources.
2. Record the actual repository URL and exact commit or release identifier once available, plus the date you accessed it. Do not use a mutable branch name as if it were an immutable version.
3. Include the synthetic-data setting, parameter/noise assumptions and relevant limits when quoting numerical results.
4. Attribute upstream algorithms, papers and copied code to their original authors. See [THIRD_PARTY.md](THIRD_PARTY.md) and the source records in each study.

Until publication, private/local copies can be identified by the archive name and the specific file digest supplied with the research exchange; this is not a public citation identifier or independent authenticity guarantee.

## Metadata still to confirm

After those details are confirmed, add a valid `CITATION.cff` so GitHub can generate formatted citations. This file deliberately does not ship a placeholder author, made-up paper or fabricated release.
