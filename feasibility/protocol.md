# 可行性复现协议

## 范围

本阶段运行上游热方程例子、上游 BoTorch 多保真教程，以及一个独立的网格成本/误差实验。不实现优化产品，不把数值解视为实际设备真值。

依赖：Python 3.12、py-pde 0.59.0、BoTorch 0.18.1、PyTorch 2.8.0 CPU。完整传递依赖见 requirements.lock。上游源码按 commit 固定，原文件及获取 SHA-256 见 upstream/manifest.json。

## 上游复现

- py-pde 的 examples/simple_pdes/simple.py 原样执行，使用 Agg 无窗口绘图并保存结果。
- 提取上游 test_simple_diffusion_value、test_simple_diffusion_flux_right、test_simple_diffusion_flux_left 的原始 AST，给 rng 参数传入固定种子的生成器，保留原测试断言。这不是上游完整 pytest 测试集。
- BoTorch 原生 continuous multi-fidelity tutorial 全部代码单元按顺序执行，仅将不可达 Colab 分支里的 pip magic 替换成 pass。
- 采用上游 SMOKE_TEST=1：每条优化流程 2 轮、每轮 2 个候选。固定 torch/NumPy 种子 20260924、CPU 单线程。
- 上游 MFKG/EI 使用不同初始随机样本和不同累计查询成本，且推荐前未用最后一批观测重拟合。保留这些行为以复现教程，不将它们解释为严格方法比较。
- 保存警告、每个代码单元时间、最终推荐、真实合成函数评估值；教程合成成本绝不当作实际秒数或完整费用。

## 热模型测量（在测量前固定）

方程：二维热扩散，∂θ/∂t = αΔθ，θ 是相对 300 K 的温差。区域为 [0,1]×[0,1] m²，全部边界零法向导数，无热源；α=0.01 m²/s，终止时间 1 s。参数是研究设定，不代表晶圆材料或设备。

初始场为三个余弦模态之和：

θ(x,y,0) = Σ a_m cos(m_x πx) cos(m_y πy)

模态为 (1,1)、(3,2)、(5,4)。每个模态随时间以 exp[-απ²(m_x²+m_y²)t] 衰减。这个连续解析解用于检查完整误差。

py-pde 的均匀单元中心二阶差分，在该边界条件下的离散模态特征值为：

λ_h = 4αN²[sin²(m_xπ/2N)+sin²(m_yπ/2N)]

用这个特征值构造半离散精确解，分离空间离散误差与时间积分误差。实施中的迹象若与该解不一致，应判失败，而不是放宽容差。

- 分辨率：16²、32²、64²、128²。对第一个工况额外计算 256²，检查继续加密。
- 方法：py-pde DiffusionPDE + NumPy backend + SciPy RK45；统一 rtol=1e-10、atol=1e-11。不是固定时间步；不同分辨率的自适应步数/稳定性限制属于其实际数值成本。
- 数据：固定种子 20260924，从 [2,10]、[0.5,5]、[0.1,2] 分别采样三个模态系数，共 8 个初始工况。
- 每个工况每档分辨率 5 次，共 160 次正式测量。全部任务固定种子打乱执行顺序；每档网格先执行一次预热，预热单独保存，不混入正式统计。
- 计时包含网格、初始场、方程/求解器构造和求解；不包含 Python 导入、误差统计、日志输出和磁盘写入。墙钟与进程 CPU 时间分别记录。
- NumPy、BLAS、OpenMP、Numba 线程设为 1，不购买算力，不运行并发的本项目计算任务；共享主机上的其他活动无法排除。
- 检查无 NaN、均值守恒、最大值原理；时间误差 <1e-6 K 且 <空间误差的 1%；RMSE 网格收敛阶介于 1.5 和 2.5。
- 对 128² 与 256² 的第一个工况使用 100 倍更严格容差，检查时间误差不决定空间收敛结论。
- 输出配对高/低分辨率耗时比、中位数和四分位距、解析解误差、收敛阶，以及 8 个工况最终空间标准差的排序关联。
- 排序关联只描述这 8 个输入上的输出，不能证明工艺优化难度或一般场景的可迁移性。

## 断点与解释边界

原始测量每条 fsync 落盘；同配置可跳过已完成项继续。若配置改变须使用新的结果目录，不能混合。若正式实验跨进程恢复，应在结论中说明不同运行条件的风险。

若高分辨率也只需很短时间，不能故意增加等待让多保真显得有用；应先对照优化器本身的实际耗时，再决定是否需要更复杂的物理任务。

即使全部通过，也只支持软件复现与数值可行性，不支持 RTP 物理准确性、AI 优于经典方法或企业商业价值。
