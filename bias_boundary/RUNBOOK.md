# 小偏置边界实验重跑说明

本目录使用已有`../feasibility/.venv`，不安装新依赖、不修改旧阶段代码或数据。

## 执行

```sh
set -o pipefail
timeout 600s ../feasibility/.venv/bin/python -u run.py 2>&1 | tee logs/rerun.log
../feasibility/.venv/bin/python -u verify.py 2>&1 | tee logs/verification-rerun.log
```

主实验完成后不重复拟合。已完成案例可复用；原拟合器发现部分调用日志但缺少完成结果时会停止，而不是静默重新拟合。要重新执行未完成拟合，须显式归档对应案例目录；修改配置或代码后，应归档整个results目录重新生成，不混跑版本。它不是优化器内部状态的精确断点恢复。

## 数据位置

- `protocol.md`：看结果之前固定的幅度、噪声、告警、隐藏标签和精化选择规则。
- `results/config.json`：对象和原算法、代码、模型、协议的SHA-256。
- `results/object-N/`：同一对象共享的无偏置真实标定、诊断和隐藏工艺场。不会因不同偏置而重新定义真值。
- `results/object-N-noise-R-bias-B/`：拟合日志、最终比值、观测/噪声/预测、冻结告警和隐藏评分。
- `refinement.json`、`refined.npz`：预设选择工况的192单元/0.0625s复核。
- `alarm96.npz`：所有组合漏报案例的96单元标定/诊断残差，再次判断原告警。
- `results/verification.json`：由独立检查器重算的各幅度计数、精化后仍存在的漏报及标签翻转。

## 解释

偏置幅度每隔0.1或0.2K取值，不能声称精确临界点。标定残差小不代表真实物性正确；诊断传感器也带同一偏置，因此“额外试验”不等于独立绝对温度参考。

检查器PASS表示配对设计、噪声、能量、判据和数值复核符合协议，不代表所有模型预测达标，也不代表没有漏报。所有结果属于研究设定，不能当实际设备故障率。

重新生成任何产物后应更新其哈希清单；运行日志与报告计时不会自动改写为新结果。
