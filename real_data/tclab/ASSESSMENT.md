# 同一热模型上的记录评估

本协议在本轮新拟合前固定。公开599行样例及100/300秒旧结果已看过，这不是盲测、独立案例或新算法评测。

## 用户任务与输入

回答“这段记录支持哪些参数结论，冻结后的预测如何，下一步缺什么”，而非自动寻找故障或功率配方。`assess.py`接受[诊断入口](DIAGNOSIS.md)的5/7列CSV及排除端点的`--before-seconds`。至少3行训练及1行后续观测；完整文件先作格式检查。

必须显式指定`--accept-model-assumptions`，表示选择本研究模型，不是设备审批：双节点对流/辐射耦合、固定环境23°C、每节点热容量2 J/K、面积0.001 m²、交换面积0.0002 m²、发射率0.9，U同时控制对外与节点间对流。沿用作者初值及边界U=[2,20] W/(m² K)、alpha1=[0.005,0.020]、alpha2=[0.002,0.015] W/%。这些是教学模型设定，不能仅因列名相同就套到其他设备；设定值列不提供环境温度。

原作者[代码](upstream/mimo_fit.py)和[旧协议](protocol.md)适合作为方程、时序、默认值和边界的来源，不适合作为普适设备模型或估计精度证明。新入口复用`thermal_model.rollout`，不修改作者或旧研究代码。

## 拟合与局部诊断

- 仅训练前缀参与拟合。初温只取首行，左端输入保持至下一行；训练末行指令没有前缀内后续观测，不算训练激励。
- 未激励的alpha固定作者默认值并标为“假设、非估计”。U仍参加拟合，是否有局部信息由灵敏度单独检查；优化器成功不证明参数能估准。
- 使用`least_squares(method=trf, jac=3-point, max_nfev=100, ftol=xtol=gtol=1e-8)`，变量仍缩放为[U,1000alpha1,1000alpha2]。目标是两通道等权摄氏度残差平方和，不除以摄氏读数，因此允许0°C。它不是噪声校准后的似然；目标与旧研究不同，新结果不得覆盖旧结果或被称作方法提升。
- 在拟合点上对全部三个参数作有限差分，步长为各参数作者范围的1e-4及5e-5；边界处截断为范围内单侧/不对称差分。导数换算为“参数改变一个范围单位时的温度变化”，不把不同量纲直接做SVD。
- 排除初始化行，将两温度输出展开；报告每列RMS灵敏度、奇异值、浮点数值秩、最弱右奇异方向、两列余弦相似度及两种步长结果差异。列为零时余弦为null，不归为可靠或故障标签。方向分量属于范围缩放坐标，在参数边界不保证两个符号方向都可行。
- 这些只是固定模型和拟合点下的局部信息，不是统计置信区间、全局结构可辨识或鲁棒性结论。无独立噪声/参考证据时，始终将估计精度标为未确立。

## 冻结与后续检验

先写`fit.json`，再生成后段预测与评分。整条模拟只在首行用实测初温；后段不重置状态、不重拟合、不参与局部诊断。保存训练/后续RMSE、MAE与有符号平均残差（含每通道），以及逐行预测CSV，便于复算；平均残差不是传感器零偏估计。

对未激励增益，另逐个取作者上下界回放，固定其他参数，检查训练预测最大差<1e-7°C并报告后续预测差和RMSE。这是外加假设敏感性，不是联合预测区间；不按后段分数选择增益。

下一步提示只据训练诊断给出：缺激励时需该路有后续观测的授权输入或独立增益标定；有输入时查看最弱方向、边界、噪声和参考，再讨论允许的补测候选。后段分数只描述预测适用性，不给未经用户定义的合格阈值。无最优候选排序、硬件动作或工程放行。

## 使用与输出

使用已有NumPy/SciPy环境，不需要Pandas、绘图包或新依赖。从仓库根执行：

```sh
.venv-tclab/bin/python -B real_data/tclab/assess.py \
  --data real_data/tclab/upstream/data.txt --before-seconds 100 \
  --accept-model-assumptions --output /tmp/tclab-assess-100
```

300秒示例使用`--before-seconds 300`及另一个新输出目录。自己的CSV必须满足相同物理假设；不同设备应先重新确定模型与协议，不以这个命令代替建模。

新目录包含运行来源/版本、拟合状态、报告JSON和中文卡片、预测CSV及局部灵敏度数组。工具拒绝已有目录（含空目录和软链），不覆写输入或历史产物；运行失败留下`status.json`与已产生的中间证据，退出2，不重试或将失败当有效评估。成功退出0不表示模型正确。默认不发布或上传输入数据。

所有新运行日志放到仓库根`output/`。本轮开发示例使用同一实测记录的100/300秒前缀，控制模型、目标、边界与算法，仅窗口不同；不能把两者计作两个独立案例。验收包含前后段隔离、零输入、末行变化、有限差分步长、0°C、优化失败、输出保护与旧证据不变。
