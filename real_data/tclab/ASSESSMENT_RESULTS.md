# 实测任务：有激励，也不代表参数可信

本轮把同一TCLab模型上的输入诊断、前缀拟合、局部参数信息和后续预测连为一个命令。它可以接收符合明确CSV契约及固定物理假设的记录；不是通用设备建模器，也没有调用合成模型推荐器来冒充实测闭环。

## 最有用的两个发现

|前缀|训练/后续行数|拟合参数U、alpha1、alpha2|局部数值秩|训练RMSE °C|后续RMSE °C|
|---|---:|---|---:|---:|---:|
|t < 100 s|100 / 499|2、0.005、0.0075（alpha2为默认假设）|2/3|1.057580|13.556313|
|t < 300 s|300 / 299|2、0.005429079、0.002974352|3/3|1.030941|2.168877|

1. **100秒：不是优化器没调好，而是记录没有alpha2信息。** 固定其余拟合参数，将alpha2分别设为作者范围两端0.002/0.015，训练预测最大差均为0°C，后续RMSE却分别为2.868108/32.812469°C。不能根据这些后段分数倒选参数，也不能把两个端点当概率区间。
2. **300秒：零输入障碍消失，仍不等于参数可信。** U仍在作者下界2；U与alpha1的范围缩放灵敏度列余弦约-0.901469，最弱局部方向主要涉及这两个量。它说明应检查参数相互补偿、模型/边界和测量前提，不足以宣布全局不可辨识、传感器故障或可靠置信区间。

有限差分步长减半后，两窗口矩阵相对差分别为约1.875e-6和1.162e-5。这是数值导数复核，不是参数估计误差。数值秩按浮点矩阵标准计算，没有把它当噪声条件下的可估性门槛。

## 这会怎样改变下一步

- 对100秒窗口，不继续把默认alpha2当估计；先查找Q2生效后的已有记录，或取得独立增益标定证据。
- 对300秒窗口，不因有输入就直接生成更大功率的试验；先审查U边界依据、固定23°C环境/热容量假设及传感器噪声。尚无完整允许候选、成本和参考证据，当前不排序最优试验。
- 后段误差仅描述同一历史运行中的预测；没有用户给定的工程容差，不判合格；没有新采集的反事实观测，不声称少做了几次试验。

## 与旧研究的关系

本轮用未加权摄氏度残差平方和，使0°C输入不发生除零；旧研究忠实复现作者相对摄氏读数目标。两者不是同目标方法对照，旧300秒coupled留出约1.8865°C与这里2.1689°C均保留，不将新目标包装为精度改善。所有旧数据、求解器、拟合程序、协议和历史结果不改。

这两个前缀来自同一条已看过的历史记录，不是两个独立案例。当前仍缺一个独立运行/工况案例、外部使用者接入证据及实际补测价值验证。
